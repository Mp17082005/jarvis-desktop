First time? Install once

  1. Download Windows ZIP
  2. Extract all in File Explorer. Open the extracted jarvis-companion folder, not the ZIP preview.
  3. Double-click Install-Jarvis.cmd. Review scripts first. Internet is required; no administrator rights needed.

Configure your own credentials before starting. In %LOCALAPPDATA%\JarvisCompanion, copy .env.example to .env; set your local access password and provider credentials. Your cloud API key is not copied.

Then double-click scripts\start_companion.cmd in that installed folder, keep its console open, and use Connect above. Approve this exact site on the local pairing page.

Installer missing or PowerShell says “file not found”?

Do not guess your download path. In File Explorer, open the extracted folder that contains Install-Jarvis.cmd and scripts. Click the address bar, type powershell, and press Enter. Run:

Test-Path .\scripts\install_companion.ps1

If it says False, you are in the wrong folder or the ZIP was not fully extracted. Extract all again and open the folder containing scripts. If it says True, the manual fallback is:

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\install_companion.ps1

The manual script requires uv. The double-click installer handles this prerequisite.

A website cannot install software automatically. Windows 10/11 with Chrome or Edge; other devices are browser-only.

Pairing & privacy

Pairing permits detection and navigation only, not remote control. Desktop actions and microphone/camera permissions stay local. Enter your local password only at http://127.0.0.1:8767. Configured AI providers can process voice and incur usage costs; the whole assistant is not offline.
