Camera & live sharing privacy

Enable camera opens a local preview only. Show Jarvis sends one snapshot or selected image to the configured AI provider for a spoken answer. When live view is off and camera is enabled, saying “Jarvis look at this”, “look at this” or “what do you see” also sends one snapshot. Your server does not store the image; provider data policies apply.


Start live view shares a frame every 5 seconds with the configured AI provider, not continuous video; changes between frames can be missed. Saying “Jarvis see me”, “see me”, “start watching” or “Jarvis start watching” also enables the camera and live sharing after browser permission. If your browser requires a tap, use Start live view. Stop watching shuts the camera off; you can also say “stop watching”, “Jarvis stop watching” or “camera off”. Provider processing and usage costs apply to each shared frame. Live view lasts only until this voice session's maintenance deadline, and stops on a hidden tab or lost connection. It never resumes automatically, including after voice renewal.


Can describe visible objects and text; not identify people or diagnose conditions. Not a safety or all-day monitoring service. Single images are resized to 1024 pixels; live frames to 640 pixels. Image-based tool actions are disabled; explicitly type or say details for a separate tool request.


Voice, privacy & safe actions
Start explicitly enables your microphone. Audio streams to the configured realtime provider; transcripts and tool requests go through your server. Private tool results may be sent to the configured AI provider. Background noise or speaker echo can interrupt Jarvis; this is not a reconnect. Use headphones if speaker echo causes interruptions.
End, hiding this tab, or leaving the page stops the microphone and closes this conversation. Returning never starts it automatically. Muting the microphone keeps the session open; the voice volume slider affects only Jarvis playback.
“Stop” or Interrupt cancels speech, not server actions already underway. Requests are never automatically retried. A lost connection mutes the microphone and has a 30-second grace period before closing.
Voice approval is disabled. For actions requiring permission, review the full summary and exact arguments on screen, then use Approve action or Cancel action. Jarvis only announces that an action is ready for review; it does not read action JSON or approval codes aloud. Spoken or typed phrases, including “yes” and any code shown in a server summary, never approve actions.
